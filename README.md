# 장애물 회피 알고리즘
스캔영상(로봇중심으로 반경1m내의 장애물만 표시)을 만들고 영상의 전방 180도 영역에서 장애물을 위치를 인식 
<br/>-> 좌측 ½영역에서 최단거리 장애물 검출
<br/>-> 우측1/2영역에서 최단거리 장애물 검출
<br/>-> 2개의 최단거리 장애물의 중앙방향을 구함
<br/>-> 로봇 정면방향과 각도 차이를 에러(부호있는 정수)로 정의함
